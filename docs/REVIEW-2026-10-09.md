# 全局审查与发布前检查

日期：2026-10-09。

## 范围

审查 Android 的账户、配对与证书校验、刷新并发、额度与重置卡解析、数据库迁移、
历史保留、列表交互、Widget 和后台刷新，以及仓库自带 Go Bridge 的缓存、路由和脱敏。
保留此前重置卡及账户管理改动，未修改 CodexLauncher，未发布 Release。
此前的真实电脑额度桥验收见 [联调记录](BRIDGE-INTEGRATION-2026-10-09.md)。

## 修复及优化

- 账户重命名、启停及绑定电脑与配对凭据更新使用同一写入锁，避免旧账户行覆盖新凭据。
  三个并发回归场景在修复前失败，修复后通过。
- 最新刷新状态按快照写入顺序读取；成功额度仍按数据时间选择。电脑恢复后返回旧缓存时，
  能清除上一轮离线状态，同时保持真实数据年龄；迟到的旧成功读数不会覆盖更新的数据。
- 增加账户与快照 ID 索引，支持上述读取；历史清理分别保留最后到达的状态和最新成功数据。
  通过一次遍历选择保护记录，去除整个历史副本的排序。
- 滑动操作按钮使用固定宽度与位移，避免动画每帧修改布局参数触发测量。
- 账户列表复用同一次读取的状态及成功数据；Codex 详情不再查询无意义的金额日累计。
- 额度使用率超过 100% 时保留原值，剩余额度限制在 0–100%；非法显式剩余值和非有限数仍拒绝。
- 更新 README 的依赖、置顶拖动、数据库版本和发布签名说明。

## 本轮模拟器验收

使用现有 API 36 模拟器覆盖安装 Debug APK，临时 HTTP 宿主依次返回成功、离线和同一份旧缓存。
确认恢复后列表不再沿用离线状态，数据时间保持原值；原查询顺序能复现错误，新查询命中新增索引。
同时验证超过 100% 的使用率、左滑删除二次确认、右滑置顶及重启后保持。
临时账户验收后已删除，原有 4 个账户的 ID 与凭据引用逐项比对一致。
本轮测试只证明这些交互和读取结果，不包含动画帧率测量。

初次验收遇到 ADB 服务断开，改用独立服务端口后完成；临时宿主最初使用微秒时间格式被手机拒绝，
改为协议支持的毫秒 UTC 格式后通过。以上为测试环境问题，未修改产品解析规则来迁就测试。

## 发布边界

当前版本仍为 `versionCode 57 / versionName 4.0.0`，已有 `v4.0.0` 标签。
正式发布前需确定新版本、递增版本号，使用固定发布密钥签名并检查最终安装包。
本轮未重新验证实体手机相机扫码和局域网防火墙；历史联调记录不能替代发布包的最终设备验收。
测试通过说明已覆盖场景满足断言，不代表不存在其他缺陷；没有进行持续负载或系统级性能基准测试。
